     module has no exports, no guard and no top-level await, so merely naming
     it in an import list aborts process startup.
  2. src/worker.ts line 1:
         import './verification-defect.ts';
     A bare side-effect import. src/cli.ts imports ./worker.ts and
     scripts/build.mjs bundles from src/cli.ts, so esbuild inlined the defect

     (/worker.cjs:1:7) instead of a frame inside worker.ts: at the point of
     failure the fault was indistinguishable from a corrupted bundle.
